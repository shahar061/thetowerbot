# R02 — Progress disposable accounts to reroll prerequisites

**Status:** Not started

**Internal dependencies:** R01

**External dependencies:** Base B07, F02, F03, F04 complete

## Outcome

Add a constrained early-game reroll policy that selects only verified affordable battle and Workshop actions, observes Tier 1 progression/unlocks, and routes run endings through durable maintenance until the guide prerequisites are confirmed.

## Acceptance gate

The policy reaches a recorded prerequisite checkpoint on replay and on a disposable live account without spending reserved currencies or choosing disallowed upgrades. A blocked unlock, unaffordable action, unreadable row or interrupted run produces an explainable wait/recovery state.

## File map

- Inspect/modify: `policy.py`, `strategy.py`, `autopilot.py`, `shopping.py`, `maintenance.py`, `progression.py`
- Create when absent: `reroll_policy.py`
- Focused verification: `tests/test_reroll_policy.py`, `tests/test_autopilot_policy.py`, `tests/test_maintenance.py`

## Implementation constraints

- Store guide thresholds as versioned, observed policy inputs; never treat a community-guide value as a universal unlock fact.
- The established account cannot load this disposable policy without explicit campaign scope.
